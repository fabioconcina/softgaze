# Changelog

## 0.1.1 - 2026-11-12

- The panel lets the softgaze window write to the clipboard, so **Copy**
  on a note works inside VS Code. Notes come with softgaze 0.2.0.

## 0.1.0 - 2026-11-10

First release.

- **Softgaze: Open** opens the window in a VS Code window of its own, with
  a locked editor group.
- **Softgaze: Toggle** (`Ctrl+Alt+J`) moves between Softgaze and the
  session in VS Code.
- Each VS Code window reports to the softgaze app whether it has the
  keyboard, so the minutes counter works on macOS.
